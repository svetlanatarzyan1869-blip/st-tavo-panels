# Tavo · Плашки сюжета (обе панели)

Расширение «Tavo · Плашки сюжета (обе панели)» больше не поддерживается автором и отключено. Его можно удалить: Расширения → Управление расширениями → значок корзины. Чаты и персонажи не пострадают.

This extension is no longer supported and has been turned off. You can uninstall it in Extensions → Manage extensions.
