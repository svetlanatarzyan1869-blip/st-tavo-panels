# Tavo · Плашки сюжета — обе панели одним расширением

Ставится **одной ссылкой** и даёт сразу две панели под последним сообщением бота:

- **🎬 варианты развития** — как может продолжить сюжет БОТ. Карусель с типами
  (Драма/Романтика/Спокойствие/Напряжение/Тайна/Неожиданное), кнопки «▶️ пусть бот так и сделает»,
  «🎲 Рискнуть» (сюрприз-ход не глядя), «🙈 подсмотреть» (тизер), реролл.
- **🎭 варианты для меня** — что может сделать ТВОЙ персонаж (действия/мысли/эмоции, свой POV).
  Кнопка «✍️ так и сделаю»: пишет полноразмерный ход за тебя в твоём стиле → постит → бот отвечает.

Генерация — через уже настроенное в SillyTavern подключение (твоя модель и пресет), ключи не нужны.
Панели свёрнуты по умолчанию, варианты сохраняются и переживают перезаход в чат.

## Установка (можно с телефона)
1. SillyTavern → иконка Extensions (кубики) наверху
2. **Install extension**
3. Вставь: `https://github.com/svetlanatarzyan1869-blip/st-tavo-panels`
4. Обнови страницу — плашки появятся под ответом бота

Нужна только одна из панелей? Есть отдельные:
[st-tavo-ideas](https://github.com/svetlanatarzyan1869-blip/st-tavo-ideas) ·
[st-tavo-me](https://github.com/svetlanatarzyan1869-blip/st-tavo-me)
(не ставь отдельную вместе с этой — панель задублируется).

## Настройки (вверху `index.js`, в каждой секции свои)
- `VARIANTS_COUNT` — сколько вариантов (по умолчанию 5)
- `SHOW_MYSTERY` — карточка-загадка в первой панели (по умолчанию да)
- `CONTEXT_MESSAGES` — сколько последних сообщений уходит модели (по умолчанию 12)
